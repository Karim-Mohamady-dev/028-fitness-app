# بلس فت — تطبيق لياقة

صفحة هبوط ثنائية اللغة (العربية RTL والإنجليزية LTR) لتطبيق لياقة، بتصميم داكن، مع مخطّط أسبوعي تفاعلي (اختيار خطة وتحديد أيام التدريب) وقائمة عادات يومية، وكلها محفوظة في localStorage.

## التشغيل
```bash
npm install
npm run dev
npm run build
```

## التقنية
React + TypeScript + Vite + Tailwind CSS، وأيقونات Phosphor.
